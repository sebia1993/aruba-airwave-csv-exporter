## 변경하면 안 되는 외부 계약

- 서버 등록 최대 5대, 기본 병렬 3대, 나머지 FIFO 큐
- Windows 예약 작업 한 개, 기존 CLI 매개변수, 한국어 GUI의 사용자 액션
- Devices > List, Default View = Devices, Top, 모든 폴더 확장, 최소 15초 최대 30초 로딩 확인
- 서버별 CSV 원본과 latest.csv, 파일명 규칙, CSV 구분자·헤더와 컬럼, 오류 재시도 기본 180초 최대 2회
- 비밀번호는 Windows Credential Manager, 실서버 URL/계정/장비 CSV는 공개 GitHub 저장소에 업로드 금지
- 정상적인 서버 URL·계정 정보 수정 방식은 유지(신규 재인증 절차 요구 기능 추가 금지)

## 접근법

A. 프레임워크와 GUI 재작성: 테스트·변경 부담이 크고 정상 기능의 동작 변경 위험 → 제외.
B. 계층별 작은 버그 수정 및 회귀 테스트: 기존 Python/tkinter/Playwright/EXE 유지, 국소 변경과 TDD → **채택**.
C. 전부 설정 옵션으로 우회: 결함을 방치할 수 있어 부적합 → 제외.

## 필수 안정화 대상과 검증

1. **GUI 타이머 및 편집 상태**: refresh()의 반복 호출에서 after() 핸들 중복 방지, 서버 목록 선택을 불필요하게 해제/복원하지 않기. 변경 중인 이름/주소/ID/비밀번호와 선택한 행이 그대로 남아야 한다.
2. **GUI 설정 저장 원자성**: 메모리 설정을 직접 수정하고 유효성·저장을 수행하는 경로, 서버 추가/수정/삭제 시 저장 실패가 메모리/파일/자격 증명 상태를 엇갈리게 하는 경로를 수정. 비정상 저장 실패 시 이전 설정과 기존 비밀번호 보호.
3. **실행 이력 손상/중단 복구**: JSON 파손/쓰기 실패로 GUI가 죽지 않도록 하고, 이미 실행 중인 배치를 덮어쓰지 않으면서 유휴 상태에서만 기존 중단 배치를 복구한다. 쓰기 실패 시 중단 마커를 제거하지 않는다.
4. **GUI 작업 스케줄러 조회**: 기존 표시 문자열과 확인 주기 유지, PowerShell 45초 지연 시 GUI 이벤트 루프 차단 방지.
5. **Windows 워커 종료**: Job Object 종료 요청 후 실제 종료를 확인하고 핸들을 닫기. 원래 CLI/동시 작업/시간 제한은 불변.
6. **CSV 큰 파일 메모리 부담**: 전체 파일 read_bytes 대신 스트리밍 읽기로 같은 판정을 수행. UTF-8-SIG/CP949/UTF-16 BOM/따옴표·개행·열 개수/HTML 탐지·CSV 원본 바이트는 그대로 유지한다.
7. **공개 GitHub 오염 예방**: 기존 .gitignore에 multi_config.json, server selectors 및 상태/로그 파일 패턴 보완. 정상 기능에 영향 없음.
8. **검증 확대**: 위 결함 회귀 테스트와 Windows EXE 프로세스/CSV 모의 환경 테스트를 현 CI에 추가. 실제 AirWave HTML 검증 완료라고 주장하지 않는다.
