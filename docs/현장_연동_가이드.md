# AirWave 8.2.14.0 현장 연동 및 검증 가이드

## 선택자 파일이 필요한 이유

개발 환경에서는 회사 내부 AirWave 서버의 실제 HTML DOM을 볼 수 없습니다. 화면의 ID,
CSS 클래스, 내보내기 URL을 추측하면 Down Devices 등 잘못된 목록을 다운로드할 수 있습니다.
그래서 최초 실행 시 생성되는 파일
%LOCALAPPDATA%\AirWaveCsvExporter\selectors.json
에 현장에서 검증한 CSS 선택자를 입력해야 합니다.

선택자 파일에 비밀번호, 쿠키, 세션 토큰, 사내 IP, MAC 또는 장비명을 넣지 마세요.
공개 GitHub 저장소에 실제 CSV와 사용자 설정 파일을 올리지 마세요.

## 선택자 확인 순서

1. 사내 Windows Edge에서 허용된 AirWave 조회 전용 계정으로 로그인합니다.
2. Devices > List 화면에서 Devices List 컨테이너를 찾습니다.
3. 표 내부의 Default View 드롭다운 선택자를 찾습니다. 우측 상단
   Default Expansion / Default Folder 설정과 혼동하지 마세요.
4. Default View가 반드시 Devices로 선택되어 있어야 합니다.
5. Go to folder 목록에서 Top을 선택합니다.
6. 사용 중인 상태/검색 필터가 모두 사라지는지 확인합니다.
7. Expand folders to show all devices를 클릭하고 펼침 완료 상태의
   마커(예: Collapse... 링크)를 확인합니다.
8. 실제 표의 장비 행, 총 장비 건수, Export as CSV 버튼을 확인합니다.
9. 각 CSS 선택자가 정확히 한 개의 목적 요소에 대응하는지 확인합니다.
10. 수동으로 받은 CSV 헤더와 전체 장비 수를 비교한 뒤 GUI의 지금 테스트를 실행합니다.

## 필수 CSS 키

| 키 | 대상 |
| --- | --- |
| table_root_css | Devices List / Default View / Export를 모두 감싸는 유일한 영역 |
| view_control_css | table_root_css 안의 Default View 선택 메뉴 |
| folder_control_css | Go to folder 선택기(전체 페이지 기준) |
| active_filters_css | 활성화된 검색/상태 필터만 감지하는 선택자 |
| expand_control_css | 전체 폴더 확장 클릭 |
| expanded_marker_css | 하위 폴더 확장이 완료됐음을 증명하는 표시 |
| rows_css | 실제 장비 데이터 행 |
| total_count_css | Devices List에 표시된 전체 장비 건수 |
| export_control_css | Devices List 영역 안의 Export as CSV 버튼 |

* 로그인 폼이 필요하면 login_user_css / login_pass_css / login_submit_css를 기입합니다.
* 사용자 정의 드롭다운이면 view_selected_css / view_option_css,
  folder_selected_css / folder_option_css도 설정합니다.
* 활성 필터가 남아 있으면 clear_filters_css 버튼으로 해제합니다.
* 총 건수가 "Showing 1 to 25 of 123"이면 패턴 "of ([\d,]+)"으로
  전체 장비 수 123을 추출합니다.
* devices_nav_css와 list_nav_css가 비어 있으면 접근성 이름이 정확히
  Devices, List인 링크를 각각 클릭합니다. 이 역시 현장에서 확인해야 합니다.
* CSS 설정에 성공했다는 사실은 AirWave 실장비 검증을 대체하지 않습니다.

## 자동 실행 범위

Windows의 현재 사용자에 Interactive 계정으로 매일 HH:MM에 작업을 등록합니다.
해당 사용자가 로그오프된 환경에서는 실행을 보장하지 않습니다. 화면 잠금과
로그오프는 다른 상태입니다. 작업 스케줄러 등록 뒤 사내 보안 정책에서 허용되는
범위 안에서 실제 테스트하세요. 실행 파일을 다른 폴더로 옮기면 예약을 다시 등록하세요.

- Microsoft Edge가 설치되어 있어야 합니다.
- 회사 CA 인증서는 Windows 인증서 저장소에서 신뢰돼야 합니다.
- HTTPS 검증을 비활성화하지 않습니다.
- SSO/MFA/CAPTCHA를 우회하지 않습니다.
- AirWave 설정 변경 기능은 없습니다.

## 다운로드 검증

- Default View = Devices를 Export 클릭 직전 다시 확인
- Top 폴더, 필터 없음, 하위 폴더 확장 표시도 재검증
- 15초 이후부터 30초까지 목록 로딩/총건수 안정 상태 대기
- CSV 데이터 행 개수와 UI 전체 장비 건수 비교
- HTML 오류 페이지, 0건 CSV, 잘못된 열 구조 거부
- 10% 초과 장비 감소 시 경고, latest.csv 미갱신
- 실패 시 기존 성공 CSV 보존

**미검증:** 실제 AirWave 8.2.14.0 화면 선택자, 회사 인증/프록시 정책,
다중 페이지 전체 내보내기 동작. 실제 환경 수동 대조가 최종 인수 조건입니다.
