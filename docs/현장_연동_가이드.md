# 다중 AirWave 8.2.14.0 현장 연동 가이드

Windows 11 PC에서 AirWave 3대를 먼저 검증하고, 필요 시 4~5대를 등록합니다. **실제 사내 AirWave 접근 및 CSS DOM 검증은 아직 수행하지 않았습니다.**

## 서버 추가·인증
- AirWave CSV Exporter.exe에서 HTTPS 주소/계정/비밀번호를 서버별로 등록합니다.
- 서버 ID는 airwave-01 등 불변값이며 CSV/선택자/로그 기준입니다.
- 비밀번호는 Windows 자격 증명 관리자에만 저장됩니다.
- MFA/SSO/CAPTCHA를 우회하지 않고 실패한 서버만 별도 처리합니다.

## CSS 선택자 파일 (서버마다 별도)

    %LOCALAPPDATA%\AirWaveCsvExporter\selectors\airwave-01.json
    %LOCALAPPDATA%\AirWaveCsvExporter\selectors\airwave-02.json
    %LOCALAPPDATA%\AirWaveCsvExporter\selectors\airwave-03.json

| 필수/보조 키 | 화면 요소 |
| --- | --- |
| table_root_css | Devices List 컨테이너 |
| view_control_css | **Default View = Devices** 메뉴 |
| folder_control_css | **Top** 폴더 선택 메뉴 |
| active_filters_css | 실제 적용 중인 상태/검색 필터 |
| clear_filters_css | 활성 필터 해제 |
| expand_control_css | **Expand folders to show all devices** |
| expanded_marker_css | 하위 폴더 확장 완료 표시 |
| loading_css | 목록 로딩 중 표시 |
| rows_css | 실제 장비 목록 행 |
| total_count_css | 표시된 전체 장비 건수 |
| total_count_pattern | 전체 건수를 추출할 정규식 |
| export_control_css | **Export as CSV** 버튼 |

**Default View와 Default Expansion은 서로 다른 항목입니다.**
반드시 Default View가 Devices인 상태에서 CSV를 내보냅니다. 실제 화면 CSS/HTML을 확인하지 않고 추측한 선택자를 적용하지 않습니다. 모든 장비가 표시될 때까지 최소 15초, 최대 30초 기다리며 CSV와 UI 총 건수를 비교합니다.

## 현장 인수 점검

- [ ] AirWave 1~3: 각 서버의 로그인/보기/Top/확장/대기/다운로드 검증
- [ ] 각 서버에서 실제 화면 전체 건수 = CSV 장비 행 수
- [ ] 3대 동시 실행, 별도 폴더/별도 최신본/독립 로그인 확인
- [ ] AirWave 1대 장애 중 나머지 서버 수집 계속 진행
- [ ] 4~5대 등록 시 기본 3대 실행/2대 대기열 확인
- [ ] A 재시도 180초 중 D/E의 최초 수집이 먼저 시작되는지 확인
- [ ] 중복 실행 시 두 번째 배치가 차단되는지 확인
- [ ] 10% 이상 급감 시 해당 서버의 latest.csv 보존 확인
- [ ] Windows 작업 스케줄러 1개, 로그인/잠금/전원 정책 확인
- [ ] Edge 프로세스 잔류 여부 및 CPU/RAM 사용량 점검
- [ ] 계정/주소/실제 CSV가 GitHub 또는 외부 로그로 업로드되지 않는지 확인

오류가 발생하면 해당 서버의 CSS와 로컬 JSONL 실행 로그를 확인하세요. 민감한 서버 주소·ID·IP·MAC·CSV 데이터를 공개 채팅/이슈에 붙여 넣지 마세요.
